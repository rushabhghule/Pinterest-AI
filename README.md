## Classification Approach

This repository uses a **subject-first classification principle**:

**Subject Always Overrides Context**
- The PRIMARY SUBJECT of the photograph determines classification
- Surrounding elements and context are secondary
- Examples:
  - Motorcycle on street → wheels (vehicle is subject, not street)
  - Flowers in garden → another luvv (flowers are subject, garden is context)
  - Person in doorway frame → composition (frame is primary, person is element)

## Key Rules (Quick Reference)

1. **Animals:** Classify by type/age (cats → elgatooo, dogs → strays/frens, other → creatures)
2. **Flowers:** Blooming flowers only → another luvv
3. **Fruits/Nature:** Seeds, fruits, crops, plants → just Earth
4. **Vehicles:** Vehicle as primary subject → wheels
5. **Roads:** Road visible + recognizable + primary context → paths
6. **People:** Portraits → portraits/idols; as elements → composition
7. **Architecture:** Buildings → pretty bricks (temples too, unless idol sculptures)
8. **Screens:** Any phone/screen/device shown → random
9. **Composition:** Visual arrangement/structure primary → composition
